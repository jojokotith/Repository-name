# Cadastral Cleaner

Скрипт приводит в порядок список украинских кадастровых номеров перед
массовой обработкой: читает CSV или Excel, нормализует номера, убирает
дубликаты и выдаёт отчёт, в котором учтена каждая строка исходного файла.

## Что делает

- принимает номера с двоеточиями и без: `5622681900:01:001:0087` и
  `5622681900010010087`;
- убирает пробелы, включая неразрывные и невидимые символы из веб-страниц и PDF;
- проверяет формат и приводит к виду `XXXXXXXXXX:XX:XXX:XXXX`;
- находит дубликаты, в том числе записанные в разных форматах, и указывает,
  какую строку они повторяют;
- ничего не додумывает: номер, повреждённый Excel (числовая ячейка, запись
  вида `5,62E+18`), отклоняется с объяснением, а не «восстанавливается»;
- сохраняет ведущие нули и записывает номера в Excel как текст;
- различает в отчёте пустую строку, дубликат и ошибку формата.

## Установка

```bash
pip install -r requirements.txt
```

Нужен Python 3.10 или новее.

## Запуск

```bash
python cadnum.py examples/sample.csv --out out
```

| Параметр | Что делает |
|---|---|
| `input` | Файл `.csv`, `.txt` или `.xlsx` |
| `--column` | Название или номер столбца с номерами, по умолчанию первый |
| `--out` | Папка для результатов, по умолчанию `out` |

CSV читается в кодировках UTF-8 и Windows-1251, разделитель определяется
автоматически.

## Результат

В папке появляются два файла:

- `<имя>-cleaned.xlsx` — лист `Numbers` с уникальными корректными номерами и
  лист `Report` со всеми строками исходного файла: номер строки, исходное
  значение, нормализованный номер, статус и причина;
- `<имя>-cleaned.json` — то же самое плюс сводка по статусам.

Статусы: `ok`, `duplicate`, `invalid`, `empty`.

Пример на файле `examples/sample.csv` из 10 строк: 4 уникальных номера,
2 дубликата, 3 отклонены с причиной, 1 пустая строка.
