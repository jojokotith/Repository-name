# RSS Project Monitor

Скрипт следит за публичной RSS-лентой фриланс-проектов, отбирает подходящие по
категориям и ключевым словам и выгружает их в Excel и JSON. Каждый проект
попадает в выгрузку один раз: уже показанные запоминаются в SQLite.

## Возможности

- отбор по категориям и по ключевым словам (слово ищется с начала: `бот` найдёт
  «боты», но не «работа»);
- бюджет и валюта выделяются из заголовка в отдельные поля;
- если бюджета или даты в ленте нет, поле остаётся пустым — значения не
  подставляются;
- повторные попытки при временных сбоях сети;
- ошибка получения ленты (код выхода `2`) отличается от ситуации «новых
  проектов нет» (код выхода `0`);
- результат: `.xlsx` и `.json` с отметкой времени в имени файла.

## Установка

```bash
pip install -r requirements.txt
```

Нужен Python 3.10 или новее.

## Запуск

```bash
python monitor.py --category Python --category "Парсинг данных" --keyword бот --out out
```

| Параметр | Что делает |
|---|---|
| `--category` | Категория проекта, можно указать несколько раз |
| `--keyword` | Слово в заголовке или описании, можно указать несколько раз |
| `--out` | Папка для результатов, по умолчанию `out` |
| `--all` | Выгрузить все совпадения, а не только новые |
| `--url` | Адрес другой RSS-ленты |
| `--file` | Прочитать ленту из локального файла |

Проект попадает в выгрузку, если совпала любая категория или любое ключевое
слово. Без фильтров выгружаются все проекты ленты.

Для регулярной проверки добавьте команду в планировщик (cron, Планировщик
заданий Windows).
